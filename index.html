Portfolio demonstration

BonePay Demo

A simulated multi-currency digital wallet built with Flutter and Firebase. It demonstrates mobile-wallet UI, transaction workflows, QR payment-request flows, Firestore integration and server-side fee calculation using demo data.

This is a portfolio demonstration, not a production financial application. No real money moves through it. Balances are demo values, transfers are simulated, QR functionality is demonstration-only, KYC is simulated, no real financial credentials are used, and wallet state resets when the app restarts.

  • Flutter
  • Dart
  • Firebase
  • Cloud Firestore
  • Cloud Functions
  • qr_flutter
  • Provider

Technical highlights

  • Multi-currency wallet dashboard with USD, GHS, NGN and KES demo balances
  • Send Money workflow with input validation and a review-and-confirm step
  • Server-side demo fee calculation in a Firebase Cloud Function
  • Firestore transaction records, transaction history and details
  • QR payment-request generation
  • Simulated transfers and a demo KYC/profile workflow
  • Structured application state
